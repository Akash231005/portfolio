01 · Full-Stack Platform

AgriFleet

Role-based fleet management platform with Admin, Driver & Client dashboards.

ReactRedux ToolkitNode.jsExpress.jsMongoDBTailwind CSSJWT
Problem & Architecture

Fleet operators need one system that speaks three different languages: admins managing the whole fleet, drivers accepting jobs, and clients booking vehicles. AgriFleet solves this with a single MERN codebase split into three role-scoped dashboards behind one JWT-authenticated REST API, with MongoDB models for bookings, vehicles, and assignments tying it together.

Challenges & Solutions

The hard part wasn't the CRUD — it was keeping booking state, driver assignment, and dashboard views in sync without stale data. Redux Toolkit centralized that state, while RBAC middleware on the Express side made sure a driver's token could never touch an admin route, even if the frontend route guard was bypassed.

Features

Role-based authentication & RBAC, protected REST endpoints, booking management, driver assignment, a full admin dashboard, client dashboard and driver dashboard, and a responsive UI across desktop and mobile.

Testing & Future Improvements

An independent automation suite (Playwright, Jest, Supertest, Newman, GitHub Actions) covers UI, API, and integration paths. Next up: live GPS tracking for active bookings and a notifications layer for assignment updates.

CarDekho Used Car Price Prediction

Pipeline & Approach

A modular pipeline handles data cleaning, feature engineering, model training and evaluation as separate, reusable stages, run across six regression models before settling on the best performer.

Result

The optimized Random Forest model reached an R² of 0.86 with a mean absolute error of ₹1.06L, with feature-importance analysis pointing to vehicle age and maximum power as the strongest price drivers.

Deployment

The trained model is serialized with Joblib and served through a Flask app deployed on Render, taking listing details as input and returning a real-time price estimate.
